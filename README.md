# FOODIE – Restaurant Food Ordering System

A simple Restaurant Food Ordering System developed using Python. It allows customers to browse food items, place orders, manage their cart and generate bills easily.

## Features

- Display food menu and prices
- Add and remove food items from cart
- Place food orders
- Generate bills automatically
- Admin login
- Add, update and delete food items
- View order history
- Generate sales reports

## Technologies Used

- Python
- SQLite Database
- Visual Studio Code

## Purpose

This project is created to practice Python programming concepts and database connectivity while developing a simple restaurant ordering application.
